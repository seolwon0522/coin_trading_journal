## 🚀 **시작하기**

### **📋 사전 요구사항**

<table>
<tr>
<td>

**필수 도구**
- 🟢 Node.js 20+
- ☕ Java 17+
- 🐍 Python 3.11+
- 🐳 Docker & Docker Compose

</td>
<td>

**데이터베이스**
- 🐘 PostgreSQL 15+
- 🔴 Redis 7.0+

</td>
</tr>
</table>

### **⚡ 빠른 설치**

<details>
<summary><b>🔧 자세한 설치 과정 보기</b></summary>

#### **1️⃣ 저장소 클론**
```bash
git clone https://github.com/kimminkyu-link/coin_trading_journal.git
cd coin_trading_journal
```

#### **2️⃣ 환경 변수 설정**
```bash
# Frontend 환경 변수
cp frontend/.env.example frontend/.env.local

# Backend 환경 변수
cp backend/src/main/resources/application.yml.example \
   backend/src/main/resources/application.yml
```

#### **3️⃣ Docker로 DB 실행**
```bash
docker-compose up -d postgres redis
```

#### **4️⃣ 서비스 실행**

<table>
<tr>
<td>

**Backend** 🚀
```bash
cd backend
./gradlew bootRun
```
➡️ http://localhost:8080

</td>
<td>

**Frontend** 🎨
```bash
cd frontend
npm install
npm run dev
```
➡️ http://localhost:3000

</td>
</tr>
</table>

</details>

### **🐳 Docker 한 번에 실행**

```bash
docker-compose up -d
```

## 📊 **API 문서**

<div align="center">

### **🔗 주요 엔드포인트**

| 카테고리 | 메소드 | 경로 | 설명 |
|:---:|:---:|:---|:---|
| **🔐 인증** | `POST` | `/api/auth/login` | 사용자 로그인 |
| | `POST` | `/api/auth/refresh` | 토큰 갱신 |
| | `GET` | `/api/auth/me` | 현재 사용자 정보 |
| **💹 거래** | `GET` | `/api/trades` | 거래 목록 조회 |
| | `POST` | `/api/trades` | 거래 생성 |
| | `POST` | `/api/trades/sync` | Binance 동기화 |
| **💼 포트폴리오** | `GET` | `/api/portfolio` | 포트폴리오 조회 |
| | `GET` | `/api/portfolio/summary` | 포트폴리오 요약 |
| **📈 통계** | `GET` | `/api/trades/statistics` | 거래 통계 |

</div>
